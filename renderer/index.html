Recent Chrome/Edge builds encrypt their cookie store and may refuse to hand it over — Firefox is the reliable choice. Close the browser first if you get a "could not copy cookies" error.


          

            
TikTok: skip watermarkRefuse the stamped copy rather than download it silently

            

          

          
On, the watermarked stream is excluded outright — if TikTok serves nothing else the download fails and says so. Turn it off to accept a stamped video. TikTok sometimes bakes the watermark into the only stream it has, which no downloader can undo.


          
Download Size


          

            
Prefer VP9 / AV1 streamsSame quality as H.264 — ~30–50% smaller file, no re-encoding

            

          

          
When enabled, Nova picks YouTube's VP9 or AV1 stream over H.264. These are YouTube's own encodes — identical visual quality, just a more efficient codec. The download itself is 30–50% smaller so it uses less bandwidth and finishes faster. Sites that don't publish VP9/AV1 automatically fall back to H.264.


          
Smart Compression


          

            
Compress after downloadRe-encode to H.265 — same quality, ~50% smaller file

            

          

          
Uses FFmpeg to re-encode the downloaded video from H.264 to H.265 (HEVC) at CRF 28. The visual quality is indistinguishable from the original — only the file size changes. The original file is replaced once compression finishes. Compression runs after the download and takes extra time depending on video length and your CPU.


          

            
Compression speedSlower preset = smaller file, more CPU time
