## ✨ Features

- 🎬 **Watch Movies & Anime** — stream directly inside the app
- 🎵 **Music Player** — JioSaavn-powered with 320kbps streams, lyrics, and offline support
- ⬇️ **Download Anything** — YouTube, TikTok, Instagram, Twitter, Facebook & 1000+ sites
- 📚 **Local Library** — offline music scanner with ID3 tag support
- 🔄 **Auto Update** — silently updates itself from GitHub Releases
- 🧩 **Browser Extension** — one-click download from any browser
- 🎨 **Beautiful UI** — animated background, glassmorphic design

## 📥 Download

Head to the [**Releases**](https://github.com/itsabrardev/nova-downloader/releases/latest) page and download the latest installer.

```
Nova-Downloader-Setup-X.X.X.exe
```

## 🚀 Auto Update

Nova Downloader checks for updates automatically every 4 hours.  
When a new version is available, a notification appears — click **Download** and then **Restart & Install**.

## 🛠️ Development

### Prerequisites
- Node.js 18+
- Git

### Setup

```bash
git clone https://github.com/itsabrardev/nova-downloader.git
cd nova-downloader
npm install
npm start
```

### Build

```bash
npm run dist
```

## 📋 Requirements (Runtime)

- Windows 10/11 (64-bit)
- Internet connection for streaming
- `yt-dlp` and `ffmpeg` — bundled in the installer
